# V5 Adaptive Portfolio and Mission Agent

V5 preserves V4's feasibility and execution layers while removing the fixed
9 Cow / 6 Sheep and 30 Strawberry attractors. Learned Top-3 targets are blended
with demand-, price-, and opponent-aware economic targets, then projected into
one shared tile budget. Plants are never started at hour 23 because they cannot
be watered before the daily refresh. Animal work is kept on the same tile
through harvest, feed, care, and fertilizer collection whenever the current
observation permits it.

Validation and packaging commands are documented in `docs/v5_design_report.md`.
