# V54

V54 suppresses only new Wheat pickup tasks made redundant by distinct existing
Wheat carriers that can reach distinct unfed animals today. Existing routes,
pickup quantities, task priorities, strategy, and market behavior are unchanged.

The feature is disabled and rejected. It improved no-FEED missions in both the
calibration and untouched seed groups, but the untouched group regressed in
mean, P10, and minimum reward and lost 2.2 FEED actions on average. The result
supports redundant-carrier suppression as a mechanism, but not this zero-slack
policy as a release candidate.

The rating-3000 target is aspirational and unverified.
