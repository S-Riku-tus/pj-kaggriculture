the episode-held-out V72 role/relative model, V58's one-score deterministic
assignment tie-break, and a two-MAE relative-money uncertainty gate.

The safe screen found all stored local states in-domain, so this is a broad
five-day intervention and remains calibration-only until lower-tail results are
known. Rating improvement is unverified.
