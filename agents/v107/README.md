# Kaggriculture V107

V107 narrows V106's executable one-day recovery goal to the conditions fixed
before implementation: day 10 or 11, at least 500 current cash, and a crop
transfer whose destination has strictly higher visible demand than its source.
The V102 confidence, uncertainty, material-change, and deficit checks remain
mandatory. V11 still owns all concrete movement, feed, market, and feasibility
decisions; the animal-escape boundary remains V106's documented value of two.

This is an experimental candidate. The restrictions fit only eight adaptive
development forks, so untouched top-log and closed-loop confirmation are
required. A 3000 rating is an objective, not a claim.
