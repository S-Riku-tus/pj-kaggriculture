# V55

V55 retains one additional prospective Wheat carrier beyond V54's one-to-one
coverage calculation. This fixed safety buffer addresses V54's held-out FEED
regression while preserving the same deterministic, observation-only fallback.

The feature is disabled and rejected. Its calibration group improved mean and
P10 reward, but a completely untouched seed group regressed from 122964.3 to
120006.4 mean reward and from 92164 to 82249 at both P10 and minimum. A single
reserve carrier was not enough to make per-turn task suppression stable.

The rating-3000 target is aspirational and unverified.
