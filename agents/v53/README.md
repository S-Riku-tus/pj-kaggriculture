# V53

V53 tests a Wheat-specific mission contract on V14. A carrier with only
operational inventory receives a unique visible FEED target and keeps it until
completion or invalidation. Pickup quantities and all strategy/market logic are
unchanged.

The feature is disabled and rejected. Its first paired diagnostic reduced PASS
but increased no-FEED pickup missions (22.5 to 26.5), reduced FEED, WATER, and
HARVEST, and increased movement. Persistent forced routing was therefore not
the missing prerequisite for teacher-like logistics.

The rating-3000 target is aspirational and unverified.
