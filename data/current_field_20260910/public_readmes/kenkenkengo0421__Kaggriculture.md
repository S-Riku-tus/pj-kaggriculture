## 1. ゲームの基本仕様と勝利条件

<details><summary></summary>

|**項目**|**詳細・パラメータ**|**備考**|
|---|---|---|
|**勝利条件**|シーズン終了時に**最も多くの資金（お金）**を持っているプレイヤーの勝利|倉庫内の未売却アイテムは資産にカウントされません。|
|**期間**|1シーズン ＝ 30日間（1日24ターン）＝ **合計720ターン**|ターンごとの行動は両プレイヤー同時に処理されます。|
|**初期資金**|$3,000|序盤の投資（種、動物、労働力）の要です。|
|**農地（ボード）**|10×10マスのグリッド（5×5の区画×4つ）|初期は北西（NW）の1区画のみ解放。|
|**土地の拡張**|隣接する区画を $1,000 / $2,000 / $4,000 で購入可能（`BUY_LAND`）|未解放の土地には作物を植えられません。|
|**倉庫（Shed）**|種子以外のアイテムを**最大100個**まで保管可能|1日の終わりに上限を超えた分は破棄されます（オーバーフロー不可）。|

</details>

|---|---|---|---|---|---|---|---|---|
|**小麦**|一度きり|$10|$25|2日後|4日後|なし|6|毎日水やりが必要|
|**ニンジン**|一度きり|$20|$35|2日後|3日後|なし|4|毎日水やりが必要|
|**トマト**|継続|$50|$60|8日後|-|毎日|4|毎日水やりが必要|
|**イチゴ**|継続|$100|$120|10日後|-|隔日|4|毎日水やりが必要|
|**メロン**|一度きり|$80|$250|10日後|12日後|なし|6|毎日水やりが必要|
|**ガチョウ(卵)**|継続|$300|$50|4日後|-|毎日|4|毎日**小麦**が必要|
|**牛(牛乳)**|継続|$400|$160|8日後|-|2日ごと|6|毎日**小麦**が必要|
|**羊(羊毛)**|継続|$500|$200|6日後|-|3日ごと|6|毎日**小麦**が必要|

## 3. アクション（行動）ルールと制約

<details><summary></summary>

各ターン、メイン農家と雇用した農作業員はそれぞれ1つのアクションを実行できます。

| **アクションカテゴリ** | **実行可能なコマンド**                                                                  | **重要な制約・ルール**                                                |
| ------------- | ------------------------------------------------------------------------------ | ------------------------------------------------------------ |
| **移動・運搬**     | `NORTH`, `SOUTH`, `EAST`, `WEST`, `PICKUP`, `DROP`, `PLACE`                    | アイテムのやり取りは倉庫（Shed）に隣接している必要があります。                            |
| **農業（植物）**    | `PLANT`, `WATER`, `HARVEST`, `FERTILIZE`, `DIG`                                | 水やりは2日連続で怠ると**雑草**になります。肥料（Fertilize）＋水やりで収穫量がボーナス増加します。     |
| **畜産（動物）**    | `BUILD_COOP`, `BUILD_PASTURE`, `FEED`, `HARVEST`, `COLLECT_FERTILIZER`, `CARE` | 餌やり（小麦）を2日連続で怠ると**逃亡**します。`CARE`（世話）をすると次回の生産量にボーナスが上乗せされます。 |
| **市場取引**      | `BUY_SEED`, `BUY_PRODUCT`, `BUY_ANIMAL`, `SELL`                                | 取引は1ターンに最大10件まで。プレイヤー間で同時に1単位ずつ処理されます。                       |
| **雇用と拡張**     | `HIRE`, `BUY_LAND`                                                             | 1日に複数人雇うと、フィボナッチ数列的にコストが急増します（リセットは翌日）。                      |

</details>


## 4.コマンド

<details><summary></summary>

| **コマンド**                        | **引数**      | **詳細な効果と制約**                                                                                                                                       |
| ------------------------------- | ----------- | -------------------------------------------------------------------------------------------------------------------------------------------------- |
| **NORTH / SOUTH / EAST / WEST** | なし          | 指定した方向に1マス移動します 。                                                                                                                                  |
| **PICKUP**                      | `[n]`       | 小屋（Shed）に直交して隣接している場合、小屋から最大 `n` 個（デフォルトは1）のアイテムを作業員のインベントリに移動します 。※種は専用スロットに保管されており、直接 `PLANT` で消費されるためピックアップできません 。                              |
| **DROP**                        | なし          | 小屋に直交して隣接している場合、現在のインベントリ全体を小屋に投入します 。小屋の上限（デフォルト100）を超えたオーバーフロー分は破棄されます 。                                                                         |
| **PLACE**                       | `[n]`       | ①**動物の配置**: 対応する空の建造物（鶏小屋や牧草地）の上に立っている場合、インベントリから動物を1匹配置します（この際、引数 `n` は無視されます） 。<br>②**小屋への収納**: 小屋に直交して隣接している場合、インベントリから最大 `n` 個のアイテムを小屋へ移動します 。 |
| **PLANT**                       | なし          | 市場で購入した種を現在のタイルに植えます 。種は全作業員で共有されていますが、特定のターンに所持数を超えて植えようとした場合、何も植えられません 。                                                                         |
| **WATER**                       | なし          | 植物に水をやります 。1日1回で十分であり、同日に2回以上行っても無効（ノーオペレーション）になります 。                                                                                              |
| **HARVEST (植物)**                | なし          | 植物から作物を収穫し、インベントリに追加します 。1度きりの作物など、次の収穫が見込めない植物は収穫後にマップから削除されます 。                                                                                  |
| **FERTILIZE**                   | なし          | 植物に肥料を与えます 。今後3日間、1日あたりの収穫量ボーナスが2倍になりますが、このボーナスは**水やりを行った日**にしか適用されません 。                                                                           |
| **DIG**                         | なし          | 現在のタイルにある植物、雑草、鶏小屋、または牧草地を削除してスペースを空けます 。この行動による収穫物や返金は一切ありません 。                                                                                   |
| **BUILD_COOP**                  | なし          | 空いているタイルに鶏小屋（ガチョウ用）を追加します 。                                                                                                                        |
| **BUILD_PASTURE**               | なし          | 空いているタイルに牧草地（牛・羊用）を追加します 。                                                                                                                         |
| **FEED**                        | なし          | インベントリ内の小麦を使って動物に餌を与えます（1日1回で十分です） 。                                                                                                               |
| **HARVEST (動物)**                | なし          | 動物が生産した卵、牛乳、羊毛などの畜産物を収集します 。                                                                                                                       |
| **COLLECT_FERTILIZER**          | なし          | 動物から肥料を1つ収集します 。生き残っている各動物は、毎日の終わりに1つの肥料を生成します 。                                                                                                   |
| **CARE**                        | なし          | 動物の世話をします（1日1回） 。**餌（小麦）を与えた日**にこの行動をセットで行うと、次回の生産スケジュール時に支払われる収穫量ボーナスが蓄積されます 。                                                                    |
| **BUY_SEED**                    | `[作物, n]`   | 市場から指定した作物の種を `n` 個購入します 。価格は固定です 。                                                                                                                |
| **BUY_PRODUCT**                 | `[アイテム, n]` | 市場から指定した製品（小麦や肥料）を `n` 個購入します 。現在の市場価格が適用されます 。                                                                                                    |
| **BUY_ANIMAL**                  | `[動物, n]`   | 市場から指定した動物を `n` 頭購入します 。価格は固定です 。                                                                                                                  |
| **SELL**                        | `[アイテム, n]` | 指定した製品を `n` 個、市場に売却します 。売却するごとにリアルタイムで市場価格が変動します 。                                                                                                 |
| **HIRE**                        | なし          | 農作業員を1日雇用します 。同日に雇用する人数が増えるごとに、費用はフィボナッチ数列的に急増します 。                                                                                                |
| **BUY_LAND**                    | なし          | 未解放の5×5の土地（区画）を新しく購入し、農地を拡張します 。費用は購入するごとに $1,000 → $2,000 → $4,000 と上昇します 。                                                                       |


</details>



## 5. 市場経済と価格変動メカニズム

<details><summary></summary>

Kaggricultureの最も難しいポイントは、価格が共有の「市場在庫（Supply）」と「町の需要（Demand）」によってリアルタイムに変動することです。

| **経済の要素**      | **メカニズムの解説**                                      | **戦略上の注意点**                                            |
| -------------- | ------------------------------------------------- | ------------------------------------------------------ |
| **基本価格と在庫**    | すべてのアイテムは初期在庫10,000（$I_0$）からスタートし、売買によって価格が変動します。 | 最低価格は$1（下限）です。                                         |
| **供給過多（売りすぎ）** | プレイヤーが市場に売却すると在庫が増え、価格が下落します。                     | イチゴ、メロン、牛乳、羊毛などの**高級品**は供給過剰に対するペナルティが大きく、すぐに$1に暴落します。 |
| **需要増加（買い・町）** | プレイヤーが買う、または「町の施設」が消費すると在庫が減り、価格が高騰します。           | 小麦などの**必需品**は、品薄になると価格が急騰しやすい関数（sqrt/log）が設定されています。    |
| **町の施設の消費**    | 3日ごとに新しいショップが解放され、市場の在庫を4ターンごとに自動で消費し続けます。        | 後半になればなるほど町の消費（需要）が激しくなり、全体の価格が押し上げられるインフレ傾向になります。     |


</details>
