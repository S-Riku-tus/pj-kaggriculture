# Kaggriculture research hypothesis ranking

This ranking was fixed before creating a new Agent or viewing its paired outcomes. It uses the September 10 public snapshot, fresh descriptive replay extraction, the installed engine, and the frozen V111 source. Expected upside is a research judgment, not a measured treatment effect.

Evidence: E0 = mechanics/source; E1 = descriptive replay; E2 = held-out prediction; E3 = executable paired intervention; E4 = diverse meta tournament; E5 = untouched holdout; E6 = live observation. No hypothesis currently has new E4/E5 support.

Ranking criterion: competitive upside × evidence × testability, discounted for complexity and safety. H1 is selected because it directly addresses portfolio commitment while retaining an already coherent, byte-identical opening. H2 is second because it has an exact finite-horizon mechanism; it is not expected to solve the strategic gap by itself. H3 is a parallel enabling study and cannot be promoted on prediction error alone.

The primary experiment will keep V111 frozen, use only its existing default/yarn-second route alternatives, decide once at t153, and preserve the original route when a robust projected-value advantage is absent. No new crop, market-timing, terminal, or execution repair is bundled into H1. Predictions are approximate; paired relative outcomes are the selection criterion.
