# V117実戦ログ分析とV119選定報告（2026-09-17）

## 結論

V117の不振は、単純な土地購入タイミングの問題ではない。中位以下には勝てるが、
高レート帯の多品目・高回転戦略に対して、固定ポートフォリオの生産量と現金化が
day 12付近から遅れることが主因である。

現行環境で最も強い候補としてV119を作成した。これは公開state-router v3を正確に
凍結・委譲する再現可能なパッケージで、開発12戦全勝、未使用seedのholdoutでは
6勝2敗、平均マージン+7,774.4だった。rating 3000は目標であって保証ではない。

## 2. いつ差が生じるか

敗戦42局だけを比較すると、step 288ですでに平均現金差が-4,542.7、稼働タイル差が
-0.74だった。step 360では現金差-7,251.5、稼働タイル差-3.31まで拡大する。
step 480でも-6,957.5 / -3.93、step 576でも-7,431.0 / -3.95であり、終盤の
一手ではなく中盤からの累積差である。

3区画目の取得はV117側がおおむねstep 254、敗戦相手側がおおむねstep 257で、
V117の土地取得が明確に遅いわけではなかった。したがってV117で行った
BUY_LANDの数手の並べ替えだけでは、主要ボトルネックを解消できない。

## 3. 何が不足しているか

敗戦時の1局平均では、V117はPLANT 202.1、WATER 970.0、HARVEST 414.3に対し、
相手は222.4、1,070.3、440.8だった。BUY_SEED回数もV117の38.8に対して
相手は86.3である。相手の方が植え替えを多く行い、価格と需要に合わせて生産面を
回していた。

V117の最大構成は概ねWheat 47、Carrot 12、Tomato 0、Strawberry 37、Melon 7、
Goose 0、Cow 9–10、Sheep 5–6に固定される。大敗例では相手がCarrot 29、Tomato
10、Goose 5を含む構成まで切り替えていた。重要なのは特定品目を常に増やすこと
ではなく、公開されているshop・価格・市場在庫・盤面に応じて複数の完成形を
選べることである。

## 4. 候補の段階的選別

1. V112は過去に高い公開ratingを持ったが、現在の4ソース×両座席では0勝8敗、
   平均マージン-34,470.6だった。過去ratingだけでは現環境への適合を示さない。
2. V117は同じパネルで2勝6敗、平均-1,360.9だった。
3. V118はV117に安全なweed回復と終盤Carrot回転だけを加えた。V117との4戦は
   1勝1敗2分、平均+12.25で、壊してはいないが抜本改善にもならなかった。
4. 公開state-router v3は、V117およびggmljs、qeinstein、souvik、moomanに対する
   開発12戦で12勝、平均+13,687.7だったため主候補に昇格した。
5. 未使用seedではV117に4勝0敗（+12,061.8）、qeinsteinに2勝0敗（+16,689）、
   moomanに0勝2敗（-9,715）だった。holdout合計6勝2敗、平均+7,774.4である。
   同じmooman seedでV117は0勝2敗、平均-11,677だったため、敗れた条件でも
   V119のマージンはV117より1,962改善した。

## 5. V119の構造

V119は6日ごとの境界で、現在の公開市場、shop構成、自他の公開農場・資産、
自分のprivate inventoryを特徴量化し、複数の完成済みroute tapeから選択する。
seed、相手identity、episode/submission ID、replay hash、未来のshop、相手private
stateは使わない。固定経路一本のV117より、環境変化に対して戦略レベルで分岐する。

ローカルの`main.py`は上流政策を改変せず委譲する。元ソースSHA-256をテストで固定し、
提出archiveにも同じソース、Apache-2.0本文、NOTICEを同梱する。
最終archiveは`artifacts/submissions/v119.tar.gz`、SHA-256は
`9b0c3de15f89819939aeb45287591a158ef330b552d49231756ee77dd33be7cd`である。
archiveを展開した実体で両座席720 stepを再実行し、完走と元政策hashの一致を確認した。

## 6. 安全性・権利・評価上の限界

- 旧32条件の安全gateでは、家畜消失とcrop-to-weed増加によりrejectされた。
  家畜消失を再調査すると、毎局step 696でSheep 2頭、手元Wheat 0の終盤処理だった。
  観測だけを根拠に救済すると経路全体を崩すため、V119では変更していない。
- runtime/delivery failureは0で、全局720 stepを完走した。
- 公開notebookページのlicenseはApache-2.0として取得済み。ただしnotebook本文が参照する
  `provenance.json`はexportに含まれず、内蔵route tapeの二次的来歴は未確認である。
  このためV119は自動昇格・自動提出を禁止したresearch candidateである。
- 20局のローカル比較は有力な証拠だが、live matchmakingの分布、rating更新、
  新規相手への一般化を保証しない。3000到達を断言することはできない。
